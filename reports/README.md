# Session reports

Machine-readable records of agent work sessions against this repository. One
JSON file per session, named `session-<date>-<goal>.json`. Each report states
what was attempted, what changed, what was proven, and with which commands.

A report is evidence of a session, not documentation of the current system.
For current state read `AGENTS.md`, `docs/PUERTS.md`, and the latest handoff
document in `docs/`.
