## Quarantined (2)

Implemented, withheld from tool discovery, and refused by the runtime with `error_code: capability_quarantined`. Do not reach for these; `puerts_diagnostic` reports the same list under `capabilities.unavailable`.

- `puerts_level_create` - QUARANTINED 2026-08-05. Loads the map it creates, so it reaches the same PuerTS UObject binding fault as puerts_level_load; reproduced on a brand-new blank map. Withheld from discovery and refused by the runtime with capability_quarantined. Use puerts_save with level_path instead. docs/CAPABILITY_FINDINGS.md, section Unknown.
- `puerts_level_load` - QUARANTINED 2026-08-05. Bridge-driven level switching crashed the UE4.27 editor 3/3 (EXCEPTION_ACCESS_VIOLATION in LoadLevelJson UEditorLoadingAndSavingUtils::LoadMap, and asynchronously in FTickFunctionTask::DoTask). Withheld from discovery and refused by the runtime with capability_quarantined. The earlier live_verified note covered a smoke run that did not switch levels. Use puerts_save with level_path instead. docs/CAPABILITY_FINDINGS.md, section Unknown.
